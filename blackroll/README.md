# blackRoll — Премиальная доставка роллов

Сайт доставки роллов с тёмной "нори" темой, реализованный на Python + Flask.

## Структура проекта

```
blackroll/
├── app.py                 # Точка входа, инициализация Flask
├── blueprints/            # Модули Flask Blueprints
│   ├── catalog.py         # Каталог товаров (главная, категории, карточка)
│   ├── cart_api.py        # API корзины (добавление, удаление, обновление)
│   └── orders.py          # Оформление заказов
├── data/                  # Data Layer + данные
│   ├── __init__.py        # Функции работы с JSON (каталог, заказы)
│   ├── catalog.json       # Каталог товаров (6 позиций)
│   └── orders.json        # Хранилище заказов (дозапись)
├── static/
│   ├── css/
│   │   └── style.css      # Все стили (тёмная тема, адаптив)
│   ├── js/
│   │   ├── main.js        # Загрузка каталога, фильтры
│   │   ├── cart.js        # Логика корзины (модальное окно)
│   │   └── checkout.js    # Оформление заказа
│   └── images/            # Изображения товаров (опционально)
└── templates/
    ├── base.html          # Базовый шаблон (шапка, футер, модальное окно)
    ├── index.html         # Главная страница с каталогом
    ├── product.html       # Карточка товара
    ├── checkout.html      # Оформление заказа
    └── success.html       # Страница успеха
```

## Установка и запуск

### Требования
- Python 3.7+
- Flask

### Установка зависимостей
```bash
pip install flask
```

### Запуск сервера
```bash
cd blackroll
python app.py
```

Сервер запустится по адресу: http://127.0.0.1:5000

## Функционал

### Для пользователя:
- 📱 Просмотр каталога роллов с фильтрацией по категориям
- 🛒 Добавление товаров в корзину (с выбором количества)
- ✏️ Управление корзиной (изменение количества, удаление)
- 📝 Оформление заказа с указанием данных доставки
- ✅ Подтверждение заказа с сохранением в JSON

### Технические особенности:
- **Backend**: Flask + Blueprints (catalog, cart_api, orders)
- **Data Layer**: отдельный модуль `data/` для работы с JSON
- **Frontend**: чистый HTML/CSS/JS без фреймворков
- **Стили**: тёмная "нори" тема, премиальный дизайн, адаптивность
- **Хранение**: 
  - Каталог — статический `catalog.json`
  - Заказы — дозапись в `orders.json` с метаданными

## API эндпоинты

### Каталог
- `GET /api/catalog` — получить весь каталог товаров

### Корзина (работает через сессии Flask)
- `GET /api/cart` — получить содержимое корзины
- `POST /api/cart/add` — добавить товар `{id, quantity}`
- `POST /api/cart/remove` — удалить товар `{id}`
- `POST /api/cart/update` — обновить количество `{id, quantity}`
- `POST /api/cart/clear` — очистить корзину

### Заказы
- `POST /api/orders/create` — создать заказ
  ```json
  {
    "items": [{"id": 1, "quantity": 2}],
    "name": "Иван",
    "phone": "+79990000000",
    "address": "ул. Примерная, 12",
    "payment_method": "card",
    "comment": ""
  }
  ```

## Страницы сайта

- `/` — главная страница с каталогом и фильтрами
- `/product/<id>` — детальная страница товара
- `/checkout` — оформление заказа
- `/order-success/<id>` — страница успешного заказа

## Как проверить работу

1. Запустите сервер: `python app.py`
2. Откройте http://127.0.0.1:5000
3. Добавьте несколько товаров в корзину (кнопка "+" на карточке)
4. Нажмите на иконку корзины в шапке — откроется модальное окно
5. Измените количество или удалите товары
6. Нажмите "Оформить заказ"
7. Заполните форму и отправьте заказ
8. Проверьте файл `data/orders.json` — там появится новый заказ
